# 🌍 Multilingual Support (i18n)

This project now supports multiple languages with a beautiful language switcher!

## 📋 Features

### ✅ Supported Languages

- 🇬🇧 **English** (en)
- 🇻🇳 **Tiếng Việt** (vi)

### ✨ Implementation Details

#### 1. **LanguageContext** (`src/contexts/LanguageContext.tsx`)

- Global state management for language selection
- Persistent storage in localStorage
- Easy-to-use `useLanguage()` hook
- Translation function `t(key)` for all text

#### 2. **LanguageSwitcher Component** (`src/components/LanguageSwitcher/`)

- Beautiful glassmorphism design
- Smooth animations with Framer Motion
- Flag emoji display (🇬🇧/🇻🇳)
- Hover and tap effects
- Responsive sizing options

#### 3. **Translations**

All translations are centralized in `LanguageContext.tsx`:

```typescript
const translations = {
  en: {
    "common.back": "Back",
    "common.generate": "Generate",
    // ... more keys
  },
  vi: {
    "common.back": "Quay lại",
    "common.generate": "Tạo ngẫu nhiên",
    // ... more keys
  },
};
```

## 🎨 Usage

### In Components

```tsx
import { useLanguage } from "../../contexts/LanguageContext";

function MyComponent() {
  const { t, language, setLanguage } = useLanguage();

  return (
    <div>
      <h1>{t("randomNumber.title")}</h1>
      <p>{t("randomNumber.subtitle")}</p>
    </div>
  );
}
```

### Adding New Translations

1. Open `src/contexts/LanguageContext.tsx`
2. Add new keys to both `en` and `vi` objects:

```typescript
const translations = {
  en: {
    // ... existing keys
    "myFeature.title": "My Feature Title",
  },
  vi: {
    // ... existing keys
    "myFeature.title": "Tiêu Đề Tính Năng",
  },
};
```

3. Use in component: `{t("myFeature.title")}`

### Using LanguageSwitcher

```tsx
import LanguageSwitcher from "./components/LanguageSwitcher";

// Basic usage
<LanguageSwitcher />

// With custom props
<LanguageSwitcher
  size="lg"           // sm | md | lg | xl
  variant="filled"    // filled | light | outline | subtle | default
/>
```

## 💡 Best Practices

1. **Always use translation keys** - Never hardcode text in components
2. **Descriptive keys** - Use `feature.component.text` pattern
3. **Keep translations updated** - Add to all languages simultaneously
4. **Test both languages** - Switch language and verify all UI text
5. **Use variables wisely** - For dynamic content: `${t("key")} ${value}`
